# Screenshot Beautifier

Transform raw screenshots into presentation-ready visuals with mockup frames, colorful backdrop gradients, configurable padding, and smooth dropshadows.

## Features

- **Gradient & Solid Backgrounds**: Preset designer color palettes, mesh gradients, and customizable background patterns.
- **Device Frames & Windows**: Wrap captures in macOS-style window headers, browser chrome, or minimal floating bezels.
- **Customizable Shadows & Radii**: Fine-tune shadow softness, elevation, corner rounding, and canvas padding.
- **High-Res Export**: Download production-ready images for Product Hunt launches, documentation, Twitter/X posts, and portfolios.
- **Privacy First**: 100% in-browser processing via HTML5 Canvas; images never leave your machine.

## Getting Started

Open `index.html` in any modern web browser and drag-and-drop or paste an image.
